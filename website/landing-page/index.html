See It In Action

Add uncertainty to your GPT-5 code in 30 seconds

Three lines of code. That's all it takes to know when your LLM is guessing.

python main.py
# Your existing GPT-5 code
from openai import OpenAI
from pinocchio import Pinocchio # ← add this
 
client = OpenAI()
judge = Pinocchio() # downloads 25 MB model
 
question = "What is the half-life of Carbon-14?"
response = client.chat.completions.create(
model="gpt-5",
messages=[{"role": "user", "content": question}]
)
 
# Score the response
score = judge.score(response, messages=question)
 
if score >= 0.7:
print("Confident:", response.choices[0].message.content)
else:
print("Low confidence — escalating to human review")
 
$ python main.py
P(correct) = 0.94
Confident: The half-life of Carbon-14 is approximately 5,730 years.
Why Pinocchio

Everything you need. Nothing you don't.

A single model that tells you when any LLM is probably wrong.

Any Model

GPT-5, Claude, Gemini, LLaMA, Qwen — any LLM that produces text. No model internals needed.

Single Forward Pass

One pass through a tiny model. No sampling, no chain-of-thought, no multiple generations.

Calibrated Probabilities

Returns real P(correct) ∈ [0, 1], not just yes/no. AUROC 0.878 across 20+ benchmarks.

Runs on CPU

0.8B parameters, ~2 GB RAM. No GPU required. Deploy anywhere — laptop, edge, CI pipeline.

Cross-Model Transfer

Trained on GPT-5 + Qwen. Generalizes to unseen models — no retraining needed.

Multimodal

Handles both text LLM and vision-language model outputs. One model for everything.

How It Works

Three steps. Zero complexity.

Pinocchio acts as a second opinion on every LLM response.

1

Ask Any LLM

Send your question to GPT-5, Claude, Gemini, or any model via their normal API. No changes to your existing code.

2

Pass to Pinocchio

Give Pinocchio the question and answer text. It doesn't need model weights, logits, or any internals.

3

Get P(correct)

Pinocchio returns a calibrated probability. Route, filter, flag, or escalate based on the score.

Use Cases

Built for real-world deployment

From production pipelines to research workflows.

Production

Selective Prediction

Only serve answers above a confidence threshold. Abstain or escalate to a human when uncertain. Up to 85% accuracy at 50% retention.

Cost Saving

Smart Model Routing

Start with a cheap model. If Pinocchio flags low confidence, retry with a stronger model. Pay for the big model only when needed.

Safety

Error Detection

Flag likely-wrong answers for human review in high-stakes domains: healthcare, legal, finance.

Evaluation

Label-Free Accuracy

Estimate model accuracy on new data without ground-truth labels. Rank models by predicted correctness. 0.90+ rank correlation.

Research

Reward Modeling

Use Pinocchio scores as reward signals for RLHF. Identify which examples a model struggles with most.

User Experience

Confidence Indicators

Show users a confidence score alongside each response. Build trust through transparency.
